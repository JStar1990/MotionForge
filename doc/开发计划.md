# MotionForge 3D 开发计划

版本：v0.3 · 2026-10-27。依据：[3D 假人设计方案](./3D动作编辑器方案.md)。

## 1. 当前状态与路线调整

用户已确认从 2D 假人转向真实 3D 空间，采用独立自由摄像机与固定截图摄像机。当前应用仍为已完成 M0～M3、M4 图片导出增量的 2D 原型。已通过的 89 项核心测试和 25 条浏览器流程仅证明旧功能，不能算作 3D 验收。

原计划归档到 [2D 开发计划](./archive/2D开发计划-2026-10-27.md)，原 M4-06～M4-10 暂停。停止继续扩展二维侧身投影和手工遮挡顺序；3D 使用真实空间、蒙皮与深度遮挡。2D 自由骨长/体型修改不直接迁入，参考图后续按 3D/截图画面参考的需求重设计。

本轮交付为设计修订、开发路线和模型资产准备，不表示已经实现 3D 编辑器。

## 4. D1：3D 场景与双摄像机

- [ ] D1-01 锁定 Three.js 及类型依赖，新增 scene3d 模块；销毁场景时释放模型、材质、纹理和 WebGL 资源。
- [ ] D1-02 GLTFLoader 加载默认模型，验证 65 关节、骨骼路径、绑定矩阵、单位和静止姿态；保留原素材。
- [ ] D1-03 建立米制/Y-up/角色朝 +Z 的规范化场景，显示中性材质、固定灯光和编辑地面网格。
- [ ] D1-04 自由摄像机支持环绕、平移、缩放、聚焦和正/背/左/右/顶视图。
- [ ] D1-05 截图摄像机固定世界坐标，默认锁定，显示独立输出预览和自由视图中的相机视锥。
- [ ] D1-06 实现显式解锁调整、XYZ/旋转、正交范围/透视 FOV、近远裁剪面和宽高比；“采用自由视角”是一次命令。
- [ ] D1-07 输入路由隔离：拖骨骼不旋转相机，自由机不修改截图机；输出预览窗口调整大小不改变投影。

验收：真实模型可从任意角度观察；两个视图展示同一个人物状态；自由机移动不改变截图构图，截图机调整可锁定和撤销。此阶段不宣称 IK 或正式工程保存已完成。

## 5. D2：3D 姿势编辑与交互

- [ ] D2-01 固定语义骨骼映射和 rigRevision，保留 twist/辅助骨；骨骼多于 40 根时不受旧 schema 限制。
- [ ] D2-02 3D FK、局部四元数、根节点平移/旋转；界面角度与四元数转换验证。
- [ ] D2-03 手腕/脚踝 IK 和肘膝 pole target，处理共线、全伸直、折叠及不可达目标。
- [ ] D2-04 视平面、XY/XZ/YZ 与轴向拖动，配合 XYZ 数值输入、FK 旋转环、手脚独立定向。
- [ ] D2-05 局部关节限制、IK/FK 无跳变切换、目标偏差提示；不复用二维 bendSign 作为三维弯曲约束。
- [ ] D2-06 固定脚目标与根节点联动，保持骨长；一次拖动一条历史，Esc 取消。
- [ ] D2-07 前后 3D 骨架洋葱皮、选择优先级、隐藏关节拾取和快捷键焦点处理。
- [ ] D2-08 用双臂前伸、朝镜头出拳、弓步扭身进行操作与蒙皮变形验收，保存截图。

验收：三种姿势具有真实深度，自由机可从侧面验证；手脚不被拉长，pole 共线不产生 NaN 或大幅翻转，切换控制与撤销稳定。默认模型必须通过肩/肘/髋变形检查，失败时先修映射或换模型，不以视觉遮挡掩盖。

## 7. D4：截图机输出与关键帧截图

- [ ] D4-01 独立渲染目标使用截图机，宽高/DPR/窗口变化不改变输出；处理 alpha、色彩空间、抗锯齿和读回翻转。
- [ ] D4-02 “截图当前姿势”PNG，透明/纯色背景，最终预览与输出使用同一参数；固定灯光不随自由机变化。
- [ ] D4-03 关键姿势缩略图使用截图机生成；相机、材质或模型变更时清缓存重建。
- [ ] D4-04 关键姿势图包与实际帧图包，manifest 记录相机、模型哈希、FPS、尺寸、顺序和区间。
- [ ] D4-05 导出冻结快照，独立实例逐帧渲染，重复帧复用；进度、取消、显存/像素/编码字节预算及 dispose。
- [ ] D4-06 辅助层始终排除；地面/阴影/骨架线作为显式选项；参考图功能另定交付范围。

验收：自由机任意移动前后截图保持一致；调整截图机才改变构图，撤销后恢复。3/2/4 示例得到 3 张或 9 张图，重复帧一致，取消不修改编辑姿势或相机。
