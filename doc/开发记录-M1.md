# M1 骨架编辑验收

日期：2026-10-26。

## 已交付

- 默认人体骨架、左右颜色、关节点、名称提示和骨骼选择。
- 腕/踝两段 IK，其他末端 FK 旋转，根节点拖动与位置/角度输入。
- 选中肢体后切换 IK/FK，切换仅初始化当前链控制器，局部旋转不变。
- 弯曲方向翻转按钮，以及所选 IK 链旁的金色方向柄。
- 局部角度最小/最大限制，受限求解、目标偏差显示与不可达虚线。
- 滚轮缩放、空格/中键平移、适配画布；视口操作不进入编辑历史。
- 一次拖动一条撤销记录，Esc 取消，重置姿势遵守已启用的限制。

默认四肢控制器现在采用 IK。FK 模式拖动下段末端只旋转该骨段；数值角度编辑仍可用于任何骨骼。角度限制作为骨架定义变更，递增骨架版本、更新草稿/资产/关键姿势中的版本和超界旋转，整个变更可一次撤销。

## 求解边界

无约束链采用解析式两段 IK；零距离沿用已有方向，远近不可达目标夹到可达距离。受限链按弯曲侧划分下段可行角度区间：给定上段角度时解析选择下段角度，再对上段做有界采样与局部细化。以末端误差为首要选择依据，同误差优先接近上一次旋转。若限制不允许请求的弯曲侧，则返回允许范围内的姿势并展示实际偏差，不突破关节限制。

角度限制默认关闭。当前求解是数值近似，不承诺所有浮点输入下严格全局最优；测试与密集网格基准比较，并覆盖零距离、伸直、等长折叠、不等长骨段和父节点旋转。

## 后续

### 简易假人与连接修正

按参考图增加骨骼驱动的几何假人：椭圆头、分段胸腔/骨盆、渐细四肢、手脚与关节。支持假人和骨架线独立显示；控制点始终可操作。所有几何由同一 FK 世界坐标派生，未额外存储另一套姿势位置。

根据使用截图修复肩部脱节和腿根层级：增加肩骨驱动的连接块，旋转肩骨时仍连接胸腔与臂根；初版曾将两侧腿根统一位于骨盆后，后续按下方记录修正。新增前/侧身连接跨度、层级、根节点平移的数学检查，以及抬肩/张腿截图和显示开关浏览器流程。

### 侧身表达增量

根据使用反馈，修正固定正面肩髋宽度难以制作侧身的问题。增加当前姿势的身体朝向与连续角度，投影肩髋宽度、调整手脚静止方向，并按朝向排列左右肢体。保留真实四肢长度和局部旋转，重置保留朝向；从骨骼树选择后优先拾取该侧的重叠控制点。数据字段 `bodyTurn` 默认 0，旧姿势按正面兼容读取。

增量验证：59 项核心测试、13 条浏览器流程通过，类型检查、代码检查、构建通过。已检查朝左、朝右和 45° 侧身截图，以及侧身后的 IK/FK、撤销、重置和重叠关节拖动。本次不将 M4 的全工程比例编辑或任意显示顺序调整标为完成。

M2 负责姿势库、自动保存、恢复与备份。当前工程仍仅在内存中，刷新或关闭页面会丢失编辑。

假人增量验收：66 项核心测试、14 条浏览器流程、代码检查和生产构建均通过。



### 2026-10-27 正面肩髋遮挡修正

根据正面看起来像背面的反馈，撤销统一把双腿放到骨盆后的规则。正面及小角度转身（绝对角度小于 45°）的双肩与双髋均显示在躯干前；侧身则远侧肢体在后、近侧在前。肩部连接块仍位于胸腔下，肩关节球显示在上，避免露出贯穿胸腔的连接块。正面两侧使用相同明度，远侧阴影随转身逐渐加深。对应测试覆盖正面、±30°、±90°，并分别记录正面和左右侧身截图。

### 墙地背景

增加可开关的墙面/地面背景、透视网格、墙脚线和可调地面接触参考线。作为临时 UI 辅助状态，与人物共用项目坐标，缩放和平移保持一致，不拦截骨骼拖动、不进入姿势历史。已完成截图检查、编辑与平移回归检查、类型/代码检查和生产构建。

### 2026-10-27 手臂与腿交叉遮挡修正

不再按整侧肢体作为同一显示层。默认将双前臂与双手放在两条腿之前，各组内仍保留远近侧顺序；正面的上臂也在腿之前。侧身远侧上臂仍保留躯干遮挡，避免肩根层级回退。新增正面、±30°、±90° 手腿顺序检查与交叉姿势截图。73 项核心测试、相关浏览器回归、代码检查与生产构建通过。
