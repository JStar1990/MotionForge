# M3 时间轴与播放验收

日期：2026-10-27。

## 已交付

- 动作新建、命名、切换和删除，全部纳入现有工程保存及备份。
- 草稿、当前关键姿势和姿势资产以独立快照加入动作；姿势库原资产不被后续编辑修改。
- 关键姿势新增、复制、删除、命名、拖动排序、另存为姿势；所有工程变更支持撤销重做。
- 持续帧数输入和右边缘拖动，拖动释放时一次提交；块宽按帧数显示，最大 300 段/3000 帧。
- 实际帧刻度、播放头点击/拖动及键盘定位、逐帧和前后关键姿势跳转、总帧数及时长显示。
- 基于 performance.now / requestAnimationFrame 的保持式播放；循环、暂停、末帧停止、末尾重播、FPS 修改暂停、页面隐藏暂停。
- 显式草稿/动作编辑目标；编辑任一播放帧会改变所属整段，独立草稿保留。播放和空动作时骨架编辑锁定。
- 前后关键姿势洋葱皮（蓝/金色）及透明度调节，播放时隐藏；删除、缩短和撤销后播放头自动限制到有效范围。
- 修正属性区遗留的“尚未保存”文案。

## 验证

86 项核心测试通过；22 条浏览器流程通过（17 条原有回归、5 条新增时间轴流程）。类型检查、ESLint、格式检查和生产构建通过；检查真实浏览器时间轴及洋葱皮截图。

固定 A×3/B×2/C×4 得到 AAABBCCCC，共 9 帧；12 FPS 为 0.75 秒，24 FPS 为 0.375 秒。测试覆盖整段编辑、草稿/资产隔离、刷新与工程备份恢复、复制/删除/撤销、拖动排序、整次时长拖动撤销、非循环末尾、循环边界、修改 FPS 及隐藏页面暂停。

## 已知边界

动作选择、播放头、循环和洋葱皮设置为临时 UI 状态，重开后默认进入草稿。每个姿势块显示名称与时长，骨架预览位于主画布。未提供自动补间、音轨、视频导出。主包仍超过 500 kB，加载及大工程性能专项验收留待 M5。
