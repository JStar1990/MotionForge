# M2 姿势与工程保存验收

日期：2026-10-27。

## 已交付

- 姿势库新增、命名、重命名、加载、删除及骨架缩略图；编辑操作支持撤销重做。
- 姿势资产与草稿深拷贝隔离，加载后编辑不会修改原资产。
- 姿势 JSON 导入导出，校验格式版本、骨架 ID、修订及完整定义，导入生成新资产 ID。
- Dexie 工程、资源、上次工程记录；启动恢复、串行自动保存、失败提示和重试。
- 保存请求入队时捕获快照，事务写入；较旧修订不能覆盖较新修订，旧请求结果不覆盖最新保存状态。
- `.motionforge` ZIP 备份：project.json 与 assets/；工程及资源完整校验后再打开。
- 未知文件版本拒绝；缺省 bodyTurn 的版本 1 数据通过迁移入口恢复正面朝向。
- 新建/打开先处理当前保存，失败时提示先下载备份；存储失败仍能导出内存中的完整工程。
- 关闭时未完成保存或存在未提交拖动，触发浏览器原生离开提醒。

## 验证

82 项核心测试、17 条 Chrome 浏览器流程通过；类型检查、ESLint、格式检查及生产构建通过。检查了姿势库实际截图。新增测试覆盖三个资产和独立草稿的刷新恢复、加载隔离、命名删除与撤销、JSON 往返、工程在全新浏览器上下文往返并继续编辑、损坏文件不覆盖当前工程、存储写入失败仍可下载备份，以及保存队列失败后的恢复与顺序。

## 格式与限制

工程导入会分配新的本机工程 ID，以免旧备份覆盖已保存的较新修订；打开后清空历史，姿势与参数保留。姿势导入作为新资产加入库，不自动替换草稿。JSON 文件限 1 MB；工程压缩文件及声明解压大小限 50 MB。

本机保存属于当前浏览器和站点地址，不是跨设备同步；同一工程多标签并行编辑及冲突合并不在本阶段范围内。参考图文件的存储/往返通道已就绪，参考图编辑 UI 仍属 M4。主包仍有超过 500 kB 的构建提示，性能与加载优化留待 M5。
