# M0 工程与数据基础

日期：2026-10-26。

## 实现范围

- React / TypeScript / Vite 工程与中文编辑器布局。
- Zod 运行时校验，支持 Rig、PoseSnapshot、PoseAsset、KeyPose、Clip、Project。
- 默认 17 根骨骼、四条连续两段 IK 链，手脚方向段不进入 IK 链。
- 独立草稿、空姿势库、空序列；工程、UI 预览和播放状态分别管理。
- 纯数据命令历史，最多保留 100 次操作；撤销、重做也增加工程修订号。
- 根节点拖动结束提交一次，Esc 取消；FK 数值输入按 Enter / 失焦提交。
- Konva 画布、骨骼选择、左右配色、缩放及适配；统一项目坐标绘制描述。
- 默认姿势、长短不等两段骨骼、3/2/4 曝光序列和损坏工程测试夹具。

为让 M0 框架可验证，提前实现了 M1 的基础 FK 计算、坐标转换和根节点操作。M1 整体尚未验收；四肢 IK、限制求解、平移和方向柄仍待开发。

## 数据约定

`schemaVersion = 1`。像素坐标 X 向右、Y 向下，角度存弧度。骨骼 offset 相对父骨骼**起点**，沿父骨骼旋转后的局部坐标轴计量；若连接在父骨骼末端，offset 为 `{ x: parent.length, y: 0 }`。

默认根节点 `(512, 500)`，躯干长 185，颈部 32，头部 64，双肩连接段 66，上臂 115，前臂 105，手部 34，大腿 152，小腿 145，脚部 52。所有局部旋转增量初始为 0；静止角在 `src/core/rig/defaultRig.ts` 中定义，按角色自身左右命名。

所有默认控制器模式为 FK，目标由末端世界坐标初始化。M1 将在切换 IK 时重建控制器，不通过目标反向重算已保存姿势。M0 不启用关节限制，校验已支持限制范围与姿势范围检查。

工程上限：40 根骨骼、每序列 300 个关键姿势 / 3000 帧、画布单边 8192 像素、FPS 1–60。数值必须有限，骨长至少 0.001 像素，持续帧数为正整数。尺寸上限仅为数据边界，不代表已通过大图导出性能验证。

## 当前限制

不进行本地保存，不读取工程文件，不导出图片。界面显式提示当前页面内存状态，相关入口禁用。没有用 localStorage 代替计划中的 IndexedDB。M2 将实现保存订阅、串行写入、恢复与文件迁移。
